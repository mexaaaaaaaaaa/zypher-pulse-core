About ZypherMC

ZypherMC is a competitive Minecraft network built for players who want a serious PvP experience without giving up casual SMP fun. Every server in the network shares the same login, the same Discord, and the same focus on quality.

Our Servers

⚔️ PvP Duels

The flagship server. Ranked duels in 9 gamemodes with an ELO tier system from Bronze to Legend.

🛏️ BedWars

Classic BedWars with custom maps and team modes.

❤️ Lifesteal

Hardcore SMP — kill a player, take a heart. Lose all hearts, lose access.

🌲 Survival

Vanilla+ survival with land claims and community towns.

🎮 Minigames

Rotating minigame lobby — SkyWars, Spleef, TNT Run and more.

🏛️ Lobby

The central hub with NPCs to every server.

How to Join

Java Edition

Open Minecraft Java 1.20.x → Multiplayer → Add Server → play.zypermc.fun

Bedrock Edition

Servers tab → Add Server → IP play.zypermc.fun · Port 25565

FAQ

Is the server free?

Yes — free to join. Optional cosmetics support development.

How do tiers work?

Only the PvP server has tiers. You earn ELO by winning ranked duels.

Can I report a cheater?

Open a ticket in our Discord.
